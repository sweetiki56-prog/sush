# Decisions

1. **Phaser 3.90, not 4.** Phaser 4 replaced the PostFX pipeline API used for the wasteland grade and CRT shader.
2. **Procedural texture pack instead of downloaded CC0 packs.** Free iso packs differ in style and scale, and 8-direction characters in a wasteland look were not available under clear licenses. Generating everything from one palette gives a consistent Fallout-like look, zero license risk, and is reproducible (`npm run gen:assets`). Any real pack can replace frames with the same names later.
3. **Map built by script instead of Tiled.** No editor dependency; layout is readable code. Can be swapped for a Tiled export that produces the same JSON shape.
4. **Synthesized audio** via WebAudio: no audio files to license.
5. **Original setting text.** Only the style is borrowed; no names, text or assets from Fallout/Wasteland.
6. **The unwalkable ring is baked, not tiled.** Material grid + decor come from the map script and are baked into the same ground image as the playable area, so style and noise continue seamlessly. The image stays ≤ 4096 px per side (WebGL texture limit).
7. **Own attribute system, not S.P.E.C.I.A.L.** Seven plain-named attributes and original trait/perk names; mechanics resemble classic RPGs, names and text do not.
8. **A perk every level.** The mission is short (levels 1–4), so the Fallout rhythm of a perk every few levels is compressed.
9. **No gender choice.** Four looks, gender-neutral text: Russian NPC lines would otherwise need gendered variants everywhere.
10. **Keyboard via DOM listeners.** See ARCHITECTURE: avoids a Phaser 3.90 duplicate-key bug under low frame rates.
11. **Balance by simulation.** Combat numbers are tuned against seeded headless fights (`tests/unit/sim.ts`), not by feel: the test fails if a combat build stops winning or a talker starts winning the nest fight.
12. **People fight only when the story turns them.** NPCs cannot be attacked at will. A person becomes an enemy only when a dialogue choice breaks their `peace` flags (the Trust in the Chapter I finale), and every such fight has non-violent ways around it. Story figures who must survive (Шлюз) are `spare`: they leave the fight wounded instead of dying.
13. **Own WebSocket server, authoritative.** A small Node server (`ws`) runs the same room code as the browser; clients only send intents. Fair for the arena, works for every friend behind any router, and the core (`src/core`, no Phaser) already ran headless. Rejected: browser-to-browser WebRTC (NAT failures, a host who can cheat, the game ends when the host leaves) and a hosted game-server framework (another state-sync pattern next to ours).
14. **Solo is a local room.** The single-player game runs `MissionRoom` in the page through `LocalTransport`, so co-op and solo share one code path and every solo test also tests the room. The room's `Game` object is shared with the UI in solo (no mirror, the save format did not change).
15. **Shared world by reference, not a new save format.** Players of a room share the `flags` / `quests` / `stats` objects of their `GameStateData`; everything else stays per player. No migration, the `Game` API unchanged.
16. **Fights wait for animations.** The room sends each batch of combat events and continues after every client acknowledged it (20 s cap). Turn timers live in the room, not in `Combat`. Log lines are written by the room when the batch is computed.
17. **Arena builds are free, kits are not.** Attributes, skills, level (up to 6), traits and perks have no point budget; only the number of weapons and consumables is limited (`content/arena.json`). Rounds are free-for-all, first to three round wins. A point-budget mode, teams and bots are for later.
18. **No ripped assets.** Nothing from Fallout (or other games), renamed or not. New weapons, armor, stims, icons, armored hero sheets and the arena map are generated by `tools/`, with their own names.
19. **Own story: «Сушь» and the Mandate.** The game is a political detective about a pre-war water concession in a dried river basin, not a Fallout/Wasteland plot. The currency is «капли» (Trust water tokens) instead of bottle caps; the code keeps the `caps` field so saves stay valid. `docs/STORY.md` is the source for lore and the chapter order.
20. **Story staging in map data, not scripts.** Who is on the map, who talks and who fights follow flags (`if`, `peace`, `from` on actors; `cleared` hooks), so a chapter's scenes are data next to the dialogues and survive save/load without extra state. Rejected: a cutscene/script system (a second way to drive the world next to flags and dialogues).
21. **Upgrades are recipes, not item instances.** A scope on a rifle makes another weapon («Винтовка с оптикой»), so the bag stays a count per item id and saves stay v2. Rejected: per-instance items with mods and durability (a new save format and a second way to describe weapons).
22. **The contract board is a dialogue.** `content/jobs.json` is turned into the board's dialogue graph; progress is flags. It reuses the dialogue view, conditions, checks and effects, and the server needs nothing new. Rejected: a separate quest-board window and state.
23. **Time passes by sleeping, or on the move.** In a town, days move only when someone rests at the campfire: guests, restocks, breeding and daily limits hang on that. On the world map the clock runs only while the party moves (45 game minutes a real second): a day passes on the way, water is drunk, parties walk. Standing still, talking and fighting stop the clock. This keeps a turn-based game free of clock pressure. Co-op agrees by one player resting, and leaves town together after a 10-second countdown that anyone can call off.
24. **Road battles on prebuilt terrain maps.** A meeting on the world map that turns into a fight moves the room to one of a few prebuilt battlefields picked by the terrain, with the enemy party injected as map actors (`enc_*`). This reuses the whole mission room: combat, fleeing, loot and kill counting. Nothing is saved on the field, so there is no half-fought state to restore. Rejected: auto-resolved fights for the player (the game is about turn-based tactics), and generating a map for every meeting (slow, and the ground has to be baked for each).
25. **Allies are AI units on the players' team.** Caravan guards (and later story companions) join a fight as creatures with `team: 'player'`. The monster AI picks targets among its enemies by team, not just among players. The outcome counts teams, so no second combat mode is needed. An ally's death gives no XP or loot. Rejected: allies as extra player slots driven by a bot (a fake connection per ally, and turn timers to work around).
26. **Places open by conditions, not by a chapter number.** A location opens when its `open` conditions hold. That is a flag like any other, so a place can open early or late, for a side quest or a secret, without a chapter counter in the save. Its `chapter` stays only for the text on the gates. Rejected: a global chapter number that every place compares with.
27. **The ring is a mode of the one combat.** A bout is the usual turn-based fight with fists forced, a knockout instead of death and no items, detected from the boxer's `ring` actor. The loser comes round instead of a game over. Rejected: a separate boxing minigame, which would be a second combat UI and a second set of rules.
28. **The score is synthesized, and every tune is our own.** The music is WebAudio code (`src/audio/Music.ts`), like the sound effects: a brass, strings, timpani and plucked-guitar palette on a lookahead scheduler. It has original themes for the road (a march), towns, fights and the menu, with crossfades and a limiter. It is an adventure-orchestra *style*: we own every note and there is nothing to license for a Steam release. Rejected: borrowing or paraphrasing a film theme (copyright), and stock tracks for now (a licence per track, and files to ship). Recorded or commissioned music can replace a track later behind the same `music.play()`.
29. **Relics are a good II tier, measured against «Кочевник».** Each unique early weapon wins a simulated fight with a gang boss and three raiders more often than «Кочевник», the best II tier rifle, but by no more than 25 points (`tests/unit/relics.test.ts`). The edge comes from cheaper shots or a special property, not from raw damage, so they stay useful to mid-game without making the next tiers pointless. Rejected: relics as flat stat upgrades, which the simulation showed doubling the win rate.
30. **Story consequences are small engine features, not scripts.** Stage R added four general hooks instead of quest code: `secret` places on the chart shown only while their `open` holds, a trader's `friend` flag for a personal discount, a `sentry` gear mod that always spots a road ambush, and a unique party's `beaten` effects. Each is a line of data in the next quest that needs it. Rejected: per-quest code paths in the rooms.
31. **Towns are several maps linked by ways out, entered through a plan.** A town is a list of areas, each a map of its own, joined by hatched exits at the edges. From the world map a town of several known areas opens its plan with buttons, as in the classic isometric RPGs; with one known area the party walks straight in. This keeps maps small (fast to bake, easy to read) and lets towns grow by adding areas, not by redrawing. Discovery is flags: a visit, or a hint in a talk. Rejected: huge single maps per town, and scrolling from one map into the next without a loading step.
32. **Roofs are baked sprites that melt per client.** A roof is one image per building, faded out while this client's own hero stands inside. It is purely visual: each co-op player sees under the roof they stand under. Rejected: cut-away walls, which need wall art in two states; and roofs as walkability or sight rules, which would make the room depend on what a client sees.
33. **A prison is a map, not a cutscene.** An arrest takes the hero's weapons and moves the party to «Сухой док», a real map with cells, guards and a grate to the sewers. Getting out is played: a shiv from the cellmate, the warden talked round, bail, or a riot fought bare-handed beside armed prisoners. Losing a fight to the city still ends in death, as everywhere; arrest comes from a talk. Rejected: a fade-to-black «you were released» screen, which would waste the city's best set piece.
34. **One world map that grows, not a map per region.** The Солончаки are the east half of the same chart (112×48), cut into image strips for the GPU. Travel, parties and fog stay one system; old saves only need their fog widened. Rejected: a second world map with a region switch (a second travel state and a loading edge in the middle of a road).
35. **The arena is a bout with weapons.** The «Пыльная чаша» reuses the ring of Три столба (`ring: 'arms'`): own weapons, nobody dies, a result flag read by the host. A fight to the death is a separate actor that is not a ring fighter. Rejected: a separate arena mode for the story (the PvP arena is its own room and rules).
36. **Companions are allies that follow, not extra players.** A companion is the same AI ally unit as a caravan guard (decision 25), present on every map by flags and walking after the leader; orders are dialogue options that set flags. It comes back to full health between fights (no wound tracking to save), but a companion killed in a fight is gone for good. Rejected: companions as bot-driven player slots (a second kind of player, inventories to sync) and a separate party screen (the talk and the character sheet cover it).
37. **Phones play the same game, adapted by input, not by a second UI.** The 1280×720 layout scales to the screen; touch gets its own ways in (finger scrolling, pinch, two-tap aiming, a real text field for names, full screen, turn-your-phone prompt, a web manifest). Rejected: a separate mobile layout (every window twice) and on-screen virtual sticks (the game is click-to-move).
38. **A pursuit always ends.** On the world map a chaser either catches the hero (a meeting, then talk or fight) or gives up: out of sight or three hours without catching up. Standing still does not freeze a chase: the clock runs until they arrive or turn away. Rejected: pursuers that simply trail the hero until the hero chooses to stop.
39. **A healer is a number on a creature, not an inventory.** Ирга bandages a friend under half health by an AI action that costs item AP and gives back her `heal`; she carries no stims and spends nothing. Rejected: AI allies that use the hero's items (stock to sync and to lose) and a heal-over-time aura (invisible to the player).
40. **The chart grows north by moving the old land down.** The Верховья are 32 new rows on top of the one world map; everything old moved down 32 rows in the content and the tests, and old saves are moved once on load (their fog is shorter). Rejected: negative row numbers (the pathfinder, the fog, the art and the parties all count from zero) and a separate map for the north (decision 34).
41. **The ending is data, read like the journal.** Slides are entries with variants under conditions, the first match wins, like quest `alt` journals; the text never declines the hero's name. Rejected: an ending script in code (every new quest would touch it) and generated sentences from flags (stiff, and hard to keep gender-neutral).
42. **Pacifism begins as an irreversible world flag.** A dead hostile tagged `human` sets `blood_drawn`; beasts, machines and Сухостои do not. Saves made before this rule have no reliable victim-type history, so an absent flag remains eligible for «Сухие руки». Rejected: deriving pacifism from total kills, which would count creatures and machines, and migrating old saves by guessing.
