# Architecture

- **Scene flow.** `Boot` → `Menu` (the real map drifting under the grade; new game / continue / co-op / arena / settings / about) → `Create` (character dossier) → `Intro` (prologue) → `World` + `UI`. «Продолжить» goes straight to `World` + `UI`. Online: `Menu` → `Lobby` (co-op: pick a character, arena: open `Loadout`) → create a room or join by code → `World` + `UI`. A link `?room=CODE[&mode=arena]` opens the lobby with the code filled in. Returning to the main menu reloads the page. `Cursor` is last in the scene list, so the styled pointer is drawn over everything.
- **Rooms run the game; scenes only show it.** All rules live in a room (`src/core/room`, no Phaser): `MissionRoom` (the Rusty Well: NPCs, triggers, dialogues, stealth, fights, items) and `ArenaRoom` (free-for-all rounds), both on the base `Room` (players, links, an intent queue, snapshots). Clients send intents (`walk`, `interact`, `choose`, `attack`, `endTurn`, …, see `protocol.ts`); the room answers with messages (`walk` paths, `flag`, `dialogue`, `combat` batches, `you` state snapshots, `players`, `arena`). Solo is the same `MissionRoom` in the page with one player through `LocalTransport`, which shares the room's `Game` object with the UI (no mirror); online a `WsTransport` connects to the server and `NetClient` keeps a mirror `Game` replaced by `you` snapshots (the UI listens to its `sync` event).
- **Session.** `session()` (`src/session.ts`) holds the `NetClient`, the mission map, the UI event bus (`hover`, `modal`, `combat`) and `modal`/`started`. `startNew` / `load` open a local room; `adopt(net)` takes over an online connection from the lobby.
- **Two scenes run together in play.** `World` renders the map with the `WastelandFX` post pipeline and turns room messages into actors (`Cast`), map changes and combat animations; `UI` sits on top with `CrtFX` (HUD, windows, dialogue, online panels). UI subscriptions are dropped on scene shutdown.
- **Shared world, own bags.** In a room every player's `GameStateData` points at the same `flags`, `quests` and `stats` objects (the world); `character`, `hp`, `caps`, `items`, `equipped`, position and log stay per player. So the save format and the `Game` API stay the same for solo, and co-op only swaps references on join. Quest XP is granted to everyone; check XP to whoever rolled; loot to the killer.
- **Pure world model.** `src/core/world`: `Grid` (walkability/sight from the map and flags), `Mover` (path following in continuous tile space; the scene's `Actor` wraps the same class, so animation matches the room), `Hostiles` (patrols, sleep, bait, detection). The room ticks at 50 ms steps (the scene ticks it in solo, a timer on the server).
- **Fights are paced by clients.** `Fight` (`src/core/room/Fight.ts`) runs a `Combat`: each batch of events goes to all clients, and the fight continues once every connected client acknowledges it (`ack`) or after 20 s. Human turns wait for input with an optional timer (co-op 60 s, arena 30 s, solo none); disconnected players are skipped. The client (`FightView`) rebuilds a read-only `Combat` from each batch's snapshot for hit chances and paths, animates the events (`CombatAnimator`, visual only) and holds other messages until the batch is shown. Consequences (log lines, HP, XP, loot, flags) are applied by the room (`FightRules` for the mission, `ArenaRoom` for rounds).
- **Server** (`server/`): `startServer` serves `dist/` and a WebSocket at `/ws`; `Rooms` creates rooms under 5-letter codes, joins by code, reconnects by player token (kept in `localStorage`), validates every character (`validCharacter`, the dossier rules), arena build (`validLoadout`, `content/arena.json` limits) and intent (`cleanIntent`), rate-limits frames, rolls a fallen co-op party back to its pre-fight save, and drops rooms left empty for 30 minutes. Co-op rooms persist to `server/data/<code>.json` (`Store`). A crash in one room is logged, never fatal.
- **Character model** lives in `src/core/character/`: `defs.ts` (ids, formulas, types), `Character.ts` (derived values as pure functions), `BuildDraft.ts` (creation rules). The creation screen and the in-game sheet [C] share panels from `src/ui/sheet/`.
- **Keyboard** goes through `onKey()` (`src/ui/keys.ts`), a DOM listener scoped to the scene. Phaser 3.90's keyboard queue re-dispatches earlier keys when several arrive within one frame.
- **Settings** (`src/core/Settings.ts`) are stored apart from the save: sound, volume, text speed, grain/vignette, default zoom, combat speed.
- **Client-side localization.** `src/i18n/display.ts` renders reviewed English dialogue, journal entries, location and area names on the client; `src/i18n/ui.ts` pairs interface strings, and `src/ui/tips.ts` pairs loading tips. The room sends Russian fallback text plus optional dialogue node, source option indexes and check metadata; choice intents still use the visible index. `dialogueHistory` optionally records content references within v2 saves, while old rendered lines remain valid. The language preference is separate from game state; English is the default and Settings offers English/Russian with a client restart (`docs/LOCALIZATION.md`).
- **Game model** (`src/core/Game.ts`) owns state and emits `log`, `flag`, `inventory`, `stats`, `quest`, `check`. The world reacts to flags (`door_open` swaps the door frame and unblocks the tile, `pump_fixed` shows water).
- **A cast that follows the flags.** Map actors may carry `if` (present only while these flags hold), `peace` (a creature that talks as an NPC until these flags break, then turns hostile where it stands and attacks whoever provoked it once the talk ends) and `from` (appears there and walks to its post; leaves the same way). `MissionRoom.recast` re-checks the cast on every flag change and sends `spawn` / `walk` / `despawn`. Map `cleared` hooks say what a group with nobody left standing means (the nest, the Trust); triggers may `repeat` as reminders. Dialogue conditions `party` / `noParty` and the `take … party` effect look at every player's bag (a search in co-op); quest stages can carry `alt` journal lines chosen by flags.
- **Gear and the body.** `Game.gearMods()` collects armor extras, worn charms (`content/charms.json`), chems at work and withdrawal as `Mods`, and every derived value (`attr`, `skill`, `maxHp`, `maxAp`, `crit`, `sequence`, `res`) passes them to the pure functions in `character/Character.ts`. `state.equipped` has two hands, armor and two charms (`equip` intent); `state.body` holds buffs and addictions (`Game.consume`, `Game.tick`). In a fight a chem also `boost`s the combat unit at once.
- **Economy and days.** `room/Craft.ts` (recipes, bench within 2 tiles), `room/Trade.ts` (prices, `quote`, `trade`; traders' goods live in the shared `stock` next to flags), `room/Days.ts` (rest: day flag, daily flags from the map, restock, guests by `visits`, `respawn` actors). Windows open from dialogue effects (`open` → a `window` message → `Workbench` / `Barter`, shown once the talk closes). Contracts are data (`content/jobs.json`) turned into the board's dialogue by `core/jobs.ts`; kills count through `MissionRoom.jobKill` (fights and bombs).
- **The road.** `core/travel/` is pure rules:
  - `Travel.ts`: terrain, pace, the clock (`pass`), fog, A*.
  - `Parties.ts`: M&B-style parties; fights between parties last two game hours before they are decided.
  - `Encounters.ts`: meeting and battle talks, built per party template.
  The room's side lives in `room/`:
  - `Road.ts`: leaving a town, intents, the tick, riding with an escorted caravan, arrivals.
  - `Meetings.ts`: a touch opens a talk; its `encounter` effect is acted on once the talk closes.
  - `RoadBattle.ts`: the move to a prebuilt battlefield (`tools/build-encounters.mjs`, picked by terrain) with the enemy as `enc_*` actors and a friendly party as `ally_*` actors under AI (team `player`), the loot pile (`loot` / `take` / `lootDone`), and the return to the map.
  Nothing is saved while `travel.encounter` is set.
- **Towns (stage T).**
  - Maps are built by `tools/build-pillars.mjs` and `tools/build-kolyuchka.mjs` on the shared `tools/map-kit.mjs`: grid, placing, a walled building, the rim, scenery, actor checks, roads running on into the wasteland ring from any side.
  - Dialogues live per place in `src/content/dialogues/*.json` and are merged in `content/index.ts`, with one generated board per town.
  - Map `arrive` hooks fire on arrival (`goTo`) and on every morning spent there (`newDay`). Locations have `open` conditions and `reach` hooks for their gates on the world map.
  - `travel.uniques` puts one-of-a-kind parties on the map while their conditions hold. A party template's `dialogue` replaces the built meeting talk.
  - A ring bout is a mode of `startCombat`, detected from `ring` actors and ended by `boutOver`.
- **Story hooks from stage R.** Four general features carry the relic quests; each is data in the next quest that needs it.
  - A location with `secret: true` is a red cross on the chart (`token_spot`), shown only while its `open` holds; it has no map, and its `reach` hooks say what is there.
  - A trader's `friend` flag gives another tenth off once set (`room/Trade.ts` `discount`).
  - The gear mod `sentry` (a charm) always spots a road ambush (`room/Meetings.ts`); `Game.hasMod` reads yes/no mods.
  - A unique party's `beaten` effects apply when it is beaten on the road (`room/RoadBattle.ts`), for a cache it guarded.
- **Towns of several areas (stage L).**
  - A location lists its maps as `areas`. `core/places.ts` finds which place a map belongs to and which areas are known: visited ones (`seen_<map>`, set by `goTo`), or those whose `known` conditions hold.
  - A map's `exits` are drawn by `world/Exits.ts` as hatched tiles with chevrons pointing off the map. `Pointer` names them on hover. Stepping on one in `Mission.enteredTile` either leaves for the world map or moves to another area (`moved`).
  - Moving between areas uses the co-op departure countdown, with a destination (`depart.where`).
  - A hatch uses the `goto` effect.
  - On arrival at a town, `Road.ts` sends `{ t: 'town' }` when more than one area is known, and `TravelScene` opens `TownScene`, the plan. The `enter` intent walks the party in. With one known area the party enters directly.
- **Roofs.** `MapData.roofs` come from `k.building(…, roof)`. `tools/art/roofs.mjs` bakes one atlas frame per roof, `roof_<map>_<id>`. `world/Roofs.ts` fades a roof out while this client's hero stands under it. Roofs are visual only: sight and walking are the walls' business.
- **Phones.** `src/ui/touch.ts`: `TOUCH` (a coarse pointer), `dragScroll` (a finger drag becomes wheel notches), `pinchZoom` (two fingers zoom both maps), `overlayInput` (a real `<input>` over the canvas inside the fullscreen box, so the phone opens its keyboard). `index.html` locks page zoom and scrolling, asks to turn a phone held upright, and ships a web manifest for «на экран Домой»; the menu's first tap goes full screen. On touch: no drawn cursor, no film grain by default, dialogue answers are full-width rows spaced for a finger, and in a fight the first tap shows the chance and cost and a second tap on the same target acts. A window closes on a tap outside its frame only.
- **Pursuits on the world map.** A party chasing the hero re-aims every 10 game minutes; while the hero stands still the clock keeps running so pursuers close in (a meeting); a pursuer that loses sight of the hero or has not caught up in three hours turns away (`gaveUp`, six calm hours).
- **Companions.** `content/companions.json` + `core/companions.ts`. Every map gets an actor per companion (`comp_<id>`: a creature with `ally`, `companion`, a dialogue, present while `with_<id>`), so a companion is on every town map and road battlefield and in every fight by the same rules as allies. Outside a fight `Hostiles.update` walks it after the leader; the client sees it as `kind: 'ally'` and a click talks. Effects `join` (checks the limit ⌊Обаяние/3⌋) and `leave`; `stance_<id> = back` makes the AI strike only foes next to our people; a companion killed in a fight sets `lost_<id>`; no companion enters a bout. On arriving somewhere a companion says its first unsaid `bark`. Old saves: `auto` conditions make Хэнк and Ржавчик join once.
- **Bouts.** An actor with `ring: true` fights a bout with fists; `ring: 'arms'` (the arena of Соль) keeps everyone's weapons. Either way everyone is `spare` (falls instead of dying), and the result is `ring_result` (`won` / `lost` / `left`), which the host's dialogue reads and clears.
- **The ending.** `chapter9_done` shows the slides instead of a chapter table: `core/endings.ts` picks, for each slide of `content/endings.json`, the first variant whose conditions hold (no match — no slide) and fills in {name}; `ui/Ending.ts` shows them one by one with a wide «ДАЛЕЕ». The trial at the console counts evidence as a flag (`evidence`, +1 per piece shown, each once).
- **A blow on arrival.** A story event that must reach the hero wherever they are next (the hostage note of Chapter VIII) is a list of `arrive` hooks shared by several maps (`tools/hostage-hooks.mjs`); its `if` lets it fire once. People taken off the board hide by a flag in their actors' `if` (`lelya_taken`, `marta_taken`); a talk that frees them sets the flags on its last «…», because the speaker leaves the map with the flag.
- **Healers.** A creature with `heal` (Ирга) first looks for a friend under half health: next to them it bandages (`{ kind: 'tend' }` → `Combat.tend`, item AP, `heal` HP back), otherwise it walks over if it can still bandage this turn; only then does it fight.
- **Burrowers.** A creature with `burrow` (the salt snake) dives at the end of every other own turn (`under`: no target, only a burst weapon may fire into the salt) and at its next turn comes up beside the sturdiest foe. A burst or a blast drives it up, stunned (`Combat.noise`).
- **Storms and story parties on the world map.** `travel.json` `storms` are rectangles raging while their flags hold: half the sight, slower going, ambushes on open ground; the client draws a veil. A unique party may walk a `route` (the Guild caravan), and a template's `seen` flag means the hero spotted it, so it talks instead of ambushing. An escorted caravan that arrives sets `arrived_<party id>`.
- **A growing chart.** The world grid is 112×80: the Верховья in rows 0–31 (`north: 32` in `world_low.json`), Низовье and the Солончаки below. The chart image is cut into strips of 64 cells (`worldmap_low_<i>.png`) so no texture is wider than a phone allows. `fitWorld` (in `Travel`, the room's constructor and the travel scene) fits an old save: the fog is widened east and padded on top, and the party, its path and every other party move down by `north`. The size of the fog tells an old save, so the move happens once.
- **Doors by flag.** A flag `open_<id>` opens any prop with that id whose frame ends in `_closed` (a door, a grille): the frame becomes `_open` and the tile walkable (`Grid.applyFlag`).
- **Arrest.** The `confiscate` effect moves everything that fights (categories weapon, grenade, ammo, armor) from the bag into `state.confiscated`; `unconfiscate` gives it back. What was equipped stays marked and is worn again once back in the bag. It is per player, so in co-op each player gets their own things back.
- **Rooted creatures.** `CreatureDef.rooted` (the sand eels) never move or flee. The AI strikes whoever is in reach and otherwise ends its turn, so a boardwalk two tiles away is safe.
- **The world map screen.** `TravelScene` puts the chart, fog, figures and weather on one camera, which zooms and follows the party and never zooms out past the chart. The console sits on a second camera that ignores zoom.
  - Parties walk as their leader's sprite sheet (the room sends `MapParty.sheet`), with a badge over them.
  - The light of the hour comes from `world/travelArt.ts`. Cloud shadows drift, dust blows, the route runs as dashes, and the trail is dots.
  - The fog is a small canvas mask, blurred and stretched smoothly.
  - The chart comes from `tools/art/worldmap.mjs` at twice the resolution: an aged expedition map with relief, glyphs, a cartouche, a compass rose and a framed grid.
- **Loading screens.** `PreloadScene` loads only the three backdrops (JPEG from `tools/art/loading.mjs`) and the fonts, then starts `Boot`. `LoadingScene` draws a style over them: `dusk` for the start, `poster` for the first arrival somewhere, `chart` for the world map.
  - The title is set in Kelly Slab, capitals only, because its lowercase «в» reads as a Latin B. Progress is a row of water drops, and a tip runs along the bottom.
  - `loadingFor(scene, data)` ties a screen to that scene's loader. It holds for at least 0.9 s and fades.
- **Music.** `audio/Music.ts` has four synthesized tracks — `road`, `town`, `fight`, `menu` — chosen by the scenes and crossfaded. Volume comes from the `music` setting. It waits for the first user gesture, like all sound.
- **Frozen answers.** `DialogueRunner` keeps the answers shown for a node, so a changing bag (co-op hand-overs) never shifts the numbers; a chosen answer whose conditions no longer hold just shows the node afresh.
- **Every interaction is a dialogue.** NPCs, the door, crate, pump, cars and the skeleton all open a dialogue graph. Options carry conditions, effects and skill checks. This keeps puzzles in data.
- **Iso**: 64×32 tiles. `gridToScreen(x, y) = ((x−y)·32, (x+y)·16)`. Depth = sum of footprint center coords; valid because footprints are convex rectangles that never overlap actors' tiles. Flat decals (skeleton) sit below actors.
- **Ground** is one baked image (continuous noise, warped material borders, cast shadows), so there are no tile seams.
- **Wasteland ring.** The map JSON carries `outer` (terrain grid with a 34-tile margin: badlands `^`, dunes `~`, salt flat `_`), `decor` (cliffs, mesas, ruins, wrecks, pylons; drawn and depth-sorted, never picked or blocking) and `wires` (pylon pairs; sagging lines drawn in `WorldMap.addWires`). The ground image covers the ring plus 256 px padding and fades into dust haze with distance; the camera is bounded by that image, so no void is ever visible. Generated by `tools/map-outer.mjs` and `tools/art/props_terrain.mjs` (heightfield renderer for cliffs/mesas).
- **Atlas anchors**: each prop frame stores `anchor` (bottom vertex of its footprint), read from `frame.customData`.
- **Pathfinding**: 8-dir A*, no corner cutting, multi-goal (`around()` a footprint) for walking up to objects. NPC tiles are dynamic obstacles.
- **Saves**: `localStorage` v2 (`main` and `auto` slots), wrapped in try/catch; autosave after dialogues, moves and triggers. Older saves are ignored.
- **Combat.** Rules are pure TS in `src/core/combat/` (`rules.ts` to-hit, damage and armor, `Combat.ts` turn state machine returning events, `ai.ts` monster decisions, `build.ts` player/creature/barrel units). Units carry a `team` (the side by default; every arena fighter is a team alone), so the same machine runs co-op PvE and free-for-all PvP; a fight ends as soon as one team is left. Room side: `Fight` + `FightRules` / `ArenaRoom`, `ItemUse` (bait, firebomb, stims outside fights). Client side: `FightView`, `CombatAnimator`, `Fx`; the UI shows `CombatHud` from the `combat` UI event.
- **Sprites.** People and creatures share the pseudo-3D part renderer (`tools/art/chars.mjs`, `creatures.mjs`); every sheet has one column per pose, listed in `meta.json` `sheets[key].poses`, so `Actor.setPose()` and the walk animation find frames by name. Each hero look also has a sheet per armor (`hero_0_vest`, …): the room names the sheet from what a player wears and redraws them when it changes.
- **Arena map.** `tools/build-arena.mjs` builds «Пыльная чаша» (30×30, point-symmetric cover, explosive barrels, six `spawns`) with the same wasteland ring; `gen:assets` bakes one ground image per map (`meta.grounds`).
